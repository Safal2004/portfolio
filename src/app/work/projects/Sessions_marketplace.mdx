## Overview

Sessions Marketplace is a full-stack web platform that enables users to discover, book, and manage professional sessions seamlessly. The platform was designed with scalability and maintainability in mind using Django REST Framework for the backend and React for the frontend.

The project demonstrates modern full-stack development practices, secure authentication, containerization, and cloud deployment.

## Key Features

- **Secure Authentication**: Implemented JWT-based authentication and authorization for secure user access.
- **Session Management**: Users can create, browse, update, and manage sessions efficiently.
- **Booking System**: Developed a complete booking workflow allowing users to reserve and manage sessions.
- **Scalable REST APIs**: Designed modular and scalable REST APIs using Django REST Framework.
- **Containerized Deployment**: Dockerized the entire application using Docker Compose for consistent deployments.
- **Production Deployment**: Deployed the application on AWS EC2 using Nginx and Gunicorn with HTTPS support.

## Challenges and Learnings

One of the major challenges was designing a scalable backend architecture while maintaining clean separation between frontend and backend services. Implementing secure authentication flows and managing multiple Docker services in production also provided valuable hands-on experience with modern deployment practices.

Deploying the application on AWS EC2 using Nginx and Gunicorn helped deepen my understanding of Linux server administration, reverse proxy configuration, and production-grade deployments.

## Outcome

The project successfully demonstrates end-to-end full-stack development capabilities, including backend API development, frontend integration, authentication, containerization, and cloud deployment.

It strengthened my expertise in backend engineering, DevOps practices, and cloud infrastructure management while providing practical experience in building production-style applications.
