## Overview

The Usage Metering and Billing Engine is a production-style backend system designed to simulate how cloud providers track resource consumption and generate customer invoices. The platform captures storage and API usage events, aggregates usage data, and calculates billing information across multiple accounts and buckets.

The project was built to replicate real-world cloud billing workflows while emphasizing scalability, modular backend architecture, and cloud-native deployment practices.

## Key Features

- **Usage Metering Engine**: Captures and aggregates storage and API usage events across multiple accounts and buckets.
- **Automated Billing Pipeline**: Calculates usage costs and generates billing summaries based on predefined pricing rules.
- **RESTful APIs**: Exposed secure APIs for usage ingestion, account management, and billing operations.
- **Scalable Database Design**: Designed relational schemas optimized for large-scale usage tracking and reporting.
- **Hybrid Cloud Deployment**: Deployed backend services on AWS EC2, PostgreSQL on AWS RDS, and frontend on Vercel.
- **CI/CD Automation**: Implemented GitHub Actions pipelines for automated build and deployment workflows.
- **Containerized Deployment**: Dockerized backend services for consistent and portable deployments.

## Challenges and Learnings

Designing a scalable billing architecture capable of processing large numbers of usage events was one of the primary challenges. Careful database schema design and modular service separation were necessary to ensure maintainability and performance.

Implementing cloud deployment across AWS EC2, AWS RDS, and Vercel provided valuable experience in managing hybrid cloud infrastructure. Setting up automated CI/CD pipelines using GitHub Actions further strengthened my understanding of modern DevOps practices and deployment automation.

## Outcome

The system successfully simulates real-world cloud storage billing workflows by tracking resource consumption, processing usage data, and generating billing summaries efficiently.

Through this project, I gained hands-on experience in backend architecture, cloud deployment, containerization, CI/CD automation, and scalable system design, making it one of my most significant backend and DevOps projects.
